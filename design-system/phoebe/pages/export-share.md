# Export & Share

PRD §2 "Export dan share", EXP-01, EXP-02, SHR-01.

## Purpose
Pick what (Notes or MoM) and which format (PDF, Word DOCX, Markdown, WhatsApp text), preview the exact output generated by the server from one revision snapshot, then hand it to the native share sheet, Save to Files, or Copy text. Draft label is visible in the output when unreviewed. The app never claims a message was sent.

## Presentation
`.sheet` with `.presentationDetents([.large])`, from MoM editor bottom bar, Meeting detail MoM card, or overflow menu. Close (`xmark`) top-leading; swipe-down dismiss allowed (nothing to lose).

## Components
Segmented `Picker`; `List` rows with `Label` + subtitle + trailing `checkmark` (selection also exposed as `.isSelected` trait); `QLThumbnailGenerator` for PDF/DOCX preview card, full-screen `QLPreviewController` on tap; `ScrollView { Text(...).font(.callout.monospaced()) .textSelection(.enabled) }` for MD/Text; `UIActivityViewController` wrapper (needs file URL with correct name/UTI, so `ShareLink` is used only for text); `.fileExporter` for Save to Files; `UIPasteboard` for Copy.

File name comes from the server (`filename`, e.g. `weekly-sync-20261106-mom-draft.pdf`; api §5) and is used as-is for the share sheet and Save to Files.

## States

| State | UI | Action |
|---|---|---|
| No MoM yet (MoM selected) | inline `ContentUnavailableView` `doc.text` `export.noMom` + "Buat MoM" | navigates to MoM tab |
| No AI notes (Notes selected) | `export.noNotes` | — |
| No manual notes | `export.noManual` | — |
| Pending local edits | preview card shows ProgressView + `export.syncingFirst`; Share disabled until sync completes (export must use a server revision) | — |
| Pending edits & offline | warning `export.offline.pending`; Share disabled | — |
| Offline (no pending edits) with cached export of same revision + format + review status | preview from cache, Share enabled | — |
| Offline, cache exists but review status changed since (e.g. reverted to Draft) | treated as no cache | — |
| Offline, no cache | warning `export.offline`; Share disabled with reason | — |
| Generating (server renders synchronously, then file download) | preview ProgressView + `export.generating`; Share disabled (loading button) | — |
| Download URL expired before share | `GET /v1/exports/{id}` for a fresh URL, transparently once | — |
| Ready | preview; Share enabled | — |
| Failed | danger inline `export.failed` in preview card | Coba lagi |
| Conflict during sync-before-export | conflict sheet from editor (mom-editor.md) is presented; export waits | — |
| Draft | warning notice row `export.draftNotice` | — |
| Reviewed | success notice `checkmark.seal.fill` `export.reviewedNotice` | — |
| Share sheet presented | event `share_sheet_opened` | — |
| Share completed (activity returned completed=true) | nothing shown (no toast, no "sent" claim; the activity type has no public display name) | — |
| Share cancelled | nothing changes, no toast, no re-export | — |
| Copy | toast `export.copied` | — |
| Saved to Files | toast `export.savedFiles` | — |
| Save to Files failed/cancelled | failed → toast `export.saveFailed`; cancelled → nothing | — |

Exports are cached as `Caches/exports/<document_revision_id>-<draft|reviewed>.<format>` (suffix from the response's `is_draft`). Content is immutable per revision but the Draft label (mutable `reviewed_at`) and the notes header (meeting title at export time) are not, so: online, every format/document change calls `POST /v1/exports` (synchronous, deterministic, cheap) and the cache is only refreshed; offline, a cache entry is used only when its suffix matches the document's current review status.

## Accessibility
- Format rows: label "<format>, <subtitle>", `.isSelected` trait on the chosen one; the group is a radio group (`accessibilityRepresentation` with Picker if custom).
- Preview card: label "Pratinjau <format>" + hint "Ketuk dua kali untuk membuka pratinjau penuh"; text previews are readable by VoiceOver line by line.
- Disabled Share always has a visible reason (footnote above the bar) and the same text as `accessibilityHint`.
- Toasts announced politely; don't take focus.

## Interactions
- Changing document or format → `POST /v1/exports {document_revision_id, format}` (`md|whatsapp|docx|pdf`; rendered synchronously, no LLM). For `md`/`whatsapp` the response `text` feeds the preview and Copy directly; files are downloaded from `download_url` into Caches. Preview crossfades in. The Draft notice mirrors the response's `is_draft`.
- Share: file formats → `UIActivityViewController(activityItems: [fileURL])`; WhatsApp text → `[String]`. Event `export_completed` when the export file/text is produced (`POST /v1/exports` 201 + download); `share_sheet_opened` on present; the share completion handler does nothing (no toast); share result never mutates the document.
- Copy (MD/Text only) copies the exact preview text.
- Save to Files: `.fileExporter` with the downloaded file.
